# React__Expenses – historisk referanse

Dette repoet bevares som historisk referanse til den eldre utgiftsappen fra 2021. Videre utvikling skal skje i den nyere React/Vite-appen.

Siste kodecommit før denne dokumentasjonsmerknaden er [86e6ac3 – rendering list and adding chart](https://github.com/gekoparty/React__Expenses/commit/86e6ac32391a0e7960c98af535147eeb2468a914), fra 17. september 2021.

Den gamle versjonen bruker React 17, Webpack og Babel, med komponenter for liste, årsfilter, registreringsskjema og egne diagrammer. Disse delene er allerede dekket i den nyere appen med React 19/Vite, MUI, React Query, MRT og ECharts. Ikke bruk dette repoets byggoppsett, komponentstruktur eller lokale eksempeldata som grunnlag for videre utvikling av dagens app.

Lenke til repoet for den nyere React/Vite-appen er foreløpig ikke bekreftet og må legges til når riktig adresse er avklart.
